# История изменений

## 0.1.1 — 2026-11-07

- Строгое распознавание статусов Matter вместо поиска подстроки `success`.
- `LAN-проба=error` теперь останавливает preflight; исключения тоже fail-closed.
- Исправлена проверка результата `guard.sh remove`, добавлена проверка состояния после удаления.
- `ssh-exec` выбран транспортом по умолчанию для Mini 2 с Dropbear без TCP forwarding.
- MQTT-мост повторяет preflight по таймеру и **перед каждой изменяющей командой**; при сбое показывает offline.
- Яркость 0% / 0 из MQTT трактуется как выключение. Внешние числовые параметры проверяются.
- HTTP-ответы, превышающие лимит, отклоняются вместо тихой обрезки.
- Локальный `--skip-preflight` разрешён только для `direct` (loopback); для SSH запрещён.
- Новые regression-тесты, LICENSE, NOTICE, .gitignore, CI и шаблон совместимости.

## 0.1.0

- Исходная экспериментальная реализация CLI, MQTT, guard и 40 offline-тестов.
