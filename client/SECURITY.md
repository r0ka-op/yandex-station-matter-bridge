# Безопасность

Matter HTTP API `maind` **не использует аутентификацию**. На проверенной прошивке
он слушал `0.0.0.0:8765` и `[::]:8765`. Один только доступ по SSH не закрывает
доступ к самому HTTP-серверу другим клиентам сети.

Не включайте API без предварительной изоляции IPv4 и IPv6, проверки порядка
правил firewall и рабочего rollback/watchdog. В этом репозитории нет механизма
безопасного постоянного включения API и нет автозапуска патча Quasar.

`station/guard.sh` — вспомогательный пример правил. Он **не гарантирует**
защиту при правилах ACCEPT выше REJECT, изменениях firewall во время работы
или после перезагрузки. `guard.sh remove` запрещён, пока порт слушается.

`ymatter doctor` проверяет доступность из конкретного хоста; это не сканирование
всех сегментов сети. Адрес IPv6 желательно задать явно. Даже при успешном doctor
между проверкой и выполнением команд возможны изменения окружения (TOCTOU).

Не загружайте в issue реальный `config.toml`, SSH-ключи, MAC-адреса,
Matter/Fabric/NOC-секреты и полные дампы. Репозиторий не предназначен для
передачи исследовательских ключей или бинарников устройства.

Сообщения об уязвимостях: свяжитесь с сопровождающим через
https://github.com/r0ka-op (без публикации секретов в открытых issue).
