# Что было найдено

Исследователь: **[r0ka-op](https://github.com/r0ka-op)**. Дата документирования: ноябрь 2026 года.

## Суть

На рутованной Яндекс Станции Мини 2 в штатном `maind --platformd` обнаружен встроенный Matter HTTP API, обычно отключённый параметром `matter.httpControl.enabled=false`. При временной активации через механизм конфигурационных патчей Quasar удалось прочитать список сопряжённых Matter-устройств и отправлять команды их штатным Matter-соединением.

Для Эмби Лампы YNDX-00560 экспериментально подтверждены чтение OnOff, управление питанием, яркостью и Hue/Saturation. Сама лампа не рутована, её прошивка не модифицировалась. Подробные JSON-примеры: [API.md](API.md), список подтверждённых функций: [AMBI_LAMP_YNDX_00560.md](AMBI_LAMP_YNDX_00560.md).

## Что не доказано

- Работоспособность этого же HTTP API на других моделях Станций или прошивках.
- Независимое Matter-сопряжение лампы с ПК или Home Assistant.
- Запуск светомузыки с произвольного источника по UDP/4048.
- Удалённое управление лампой без Станции через этот конкретный API: он принадлежит Станции.

## Зачем скрипты

Для открытия API необходима активация конфигурации и перезапуск `platformd`. Во время исследования использовались временный патч, сетевые ограничения, watchdog, сохранение исходного состояния и rollback. Большой объём скриптов относится к безопасной автоматизации этих действий, а не к реализации Matter-протокола с нуля.

**Внимание:** этот ознакомительный архив содержит старую версию контроллеров; её аппаратные действия намеренно заблокированы. Для повторения опытов на реальном устройстве нужен проверенный текущий lifecycle и независимый аудит.
