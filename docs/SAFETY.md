# Модель безопасности

## Основная угроза

В проверенной прошивке HTTP control plane не аутентифицирует клиента и предоставляет широкие права над сопряжёнными Matter-устройствами. Listener создаётся на всех IPv4/IPv6 адресах. Поэтому встроенный сервер сам по себе нельзя считать безопасным локальным API.

## Инварианты контроллера

1. До активации API устанавливаются IPv4 и IPv6 guards, разрешающие TCP/8765 только через loopback.
2. При невозможности доказать установку guard выполнение останавливается до изменения lifecycle.
3. Patch временный; production-конфигурация и Matter storage не изменяются.
4. Station-local watchdog вооружается до первой изменяющей Matter-команды.
5. HTTP выполняется только через `127.0.0.1:8765` на самой Станции.
6. Каждый режим имеет allowlist метода, маршрута, node, endpoint, cluster, command и `fields`.
7. Состояние считается восстановленным только после Matter readback, а не после HTTP 200.
8. Сначала отключается API и подтверждается отсутствие listener; только затем снимается firewall guard.
9. Rollback идемпотентен, сохраняет первую ошибку и не повторяет lifecycle после состояния `already_clean`.
10. При неподтверждённом восстановлении сохраняется `LIGHT_STATE_MAY_BE_CHANGED`.
11. Каждый запуск имеет уникальный `run_id`, отдельный `/tmp/maind-http-runs/<run_id>` и проверяемую принадлежность маркеров.
12. Global lock `/tmp/maind-http-runtime.lock` запрещает параллельные и неоднозначные запуски; старое состояние не удаляется автоматически.

## Чего проект не делает

- не извлекает CASE/session keys, fabric credentials или Wi-Fi пароль;
- не патчит и не инжектирует код в `maind`;
- не оставляет порт 8765 открытым в LAN;
- не использует vendor-команды с неизвестной семантикой;
- не гарантирует восстановление после потери питания устройства.

Перед запуском убедитесь, что SSH остаётся доступен, сохраните диагностику предыдущего запуска, проверьте отсутствие старых workers/mounts/patches/guards и не запускайте два контроллера параллельно.

Любое ослабление firewall/watchdog/rollback требует отдельного review и регрессионных тестов.
