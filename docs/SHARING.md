# Передача материалов другому разработчику

Автор: [r0ka-op](https://github.com/r0ka-op).

Это **ознакомительная версия**; в ней сохранены исходники старых контроллеров для анализа. Их аппаратный запуск заблокирован, так как исправления lifecycle из рабочего исследования не были приложены к исходному архиву.

При передаче полезнее всего дать `README.md`, `docs/DISCOVERY.md`, `docs/API.md`, `docs/AMBI_LAMP_YNDX_00560.md` и `docs/SAFETY.md`. Если нужен код, он находится в `scripts/`, но для запуска на живой Станции его сначала нужно синхронизировать с актуальным исследовательским репозиторием.

Никакие реальные credentials, приватные ключи, дампы, IP домашней сети или OEM-бинарники в этот архив не включены.

Материалы распространяются под Apache-2.0: допускаются использование и форки при соблюдении условий лицензии, в частности сохранении необходимых уведомлений. Само существование и поведение API принадлежат штатному ПО Яндекса, а не этому проекту.
